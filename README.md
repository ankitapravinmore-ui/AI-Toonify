# 🎨 AI Toonify

AI based Image and Video Cartoon Generator built using Streamlit and ONNX.

---

## 🚀 Features
- Convert Image to Cartoon
- Sketch Effect
- Pencil Effect
- Image to Video (MP4)
- Video to Cartoon
- Login System
- Dummy Payment Integration

---

## 🛠 Technologies Used
- Python
- Streamlit
- OpenCV
- NumPy
- ONNX Runtime

---

## ▶ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
